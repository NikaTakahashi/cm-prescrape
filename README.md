# cm-prescrape — Console Mode artwork from your PC

Pre-downloads artwork for **Console Mode (MiSTer FPGA) from your PC** using the
**same source as Console Mode's original scraper** (the default
"Scrape Art (Default)" mode): the public libretro CDN
`thumbnails.libretro.com`. No account, API key or credentials needed.

Artwork is saved exactly where Console Mode expects it, so once the SSD goes
back into the MiSTer the covers show up without downloading anything again
(Console Mode will only generate its downscaled thumbnails in
`media/optimized/`).

## Output format (identical to Console Mode's)

| Content | Path |
|---|---|
| Cover art | `<ROM folder>/media/<ROM name>.png` |
| Background | `<ROM folder>/media/<ROM name>-BG.png` |

Example:

```
games/SNES/1 US - A-E/Super Mario World (USA).sfc
games/SNES/1 US - A-E/media/Super Mario World (USA).png       <- cover
games/SNES/1 US - A-E/media/Super Mario World (USA)-BG.png    <- background
```

It scans `games/` recursively (including subfolders like
`1 US - A-E`, `2 Europe`, multi-disc sets, etc.).

## Requirements

- Linux/macOS/WSL with **Python 3.8+** (no external dependencies, stdlib only).
- The MiSTer SSD/SD mounted with write permissions.

## Configuration

Edit **`config.ini`** (at least the important first line):

```ini
[path]
sd_root=/run/media/youruser/MiSTerSSD   ; SD root (the folder containing games/)
```

Other options: number of download threads (`jobs`), cover source
(`boxarts`/`snaps`/`titles`/`logos`), background source (`snaps` or `none`),
system filter (`systems=SNES,PSX`), network retries, and the optimized
thumbnails section (`[optimize]`: `enabled`, `max_width`, `max_height`).

## Usage

```bash
# 1) Interactive mode (recommended): menus to pick the media and confirm systems
python3 cm_prescrape.py

# 2) Fully automatic, no questions (uses config.ini as-is)
python3 cm_prescrape.py --all

# 3) Pilot test: 5 games from SNES and PSX (writes nothing with --dry-run)
python3 cm_prescrape.py --systems SNES,PSX --limit 5 --dry-run
python3 cm_prescrape.py --systems SNES,PSX --limit 5
```

```bash
# Only (re)generate the optimized thumbnails for artwork already on the SSD
python3 cm_prescrape.py --optimize-only

# Download without generating optimized thumbnails
python3 cm_prescrape.py --all --no-optimize

# Only scrape arcade (_Arcade/*.mra), or skip it
python3 cm_prescrape.py --arcade-only
python3 cm_prescrape.py --all --no-arcade
```

When run in interactive mode:

1. **Choose the cover art download source** (2D box art + background by
   default, which is what Console Mode uses; screenshots, title screens and
   logos also available).
2. **Automatically detects your platforms**: reads the folders in `games/`,
   matches them against the systems available on the libretro CDN and shows
   the mapping table (e.g. `games/SNES → Nintendo - Super Nintendo
   Entertainment System`). Confirm, or select only some of them.
3. **Automatically scans every ROM** of the chosen systems
   (recursive, deduplicated by name) and matches them against the CDN artwork
   (translates MiSTer-style regions `(U)/(E)/(J)` to `(USA)/(Europe)/(Japan)`).
4. **Downloads everything** in parallel, skipping files that already exist
   (you can re-run it any time: it is resumable).
5. **Generates optimized thumbnails** (like Console Mode's "Optimize Artwork")
   into `media/optimized/`, so the MiSTer doesn't have to resize anything:
   downscaled copies of every cover and background (default max 400x400 px,
   configurable in `config.ini`). Needs Pillow (`pip install pillow`).

## Files generated by the program

| File | What it is |
|---|---|
| `cache/` | Downloaded CDN listings (speeds up re-runs; delete it to refresh) |
| `download_report.csv` | Per-system summary: total ROMs / with artwork / without artwork |
| `no_artwork.csv` | Games with no artwork on the CDN (equivalent to Console Mode's `ScrapeLogs`) |

## Arcade (`_Arcade/*.mra`)

The MiSTer arcade folder lives outside `games/` (`_Arcade/*.mra` at the SD
root) and is scraped automatically in the same run, using the `MAME` +
`FBNeo - Arcade Games` CDN folders (the same long-title artwork the
`games/Mame` zips use). Matching tries, in order:

1. The `.mra` filename (`After Burner II.mra` → `After Burner II.png`),
2. the `<name>` tag inside the `.mra` (e.g. `ASO.mra` →
   `ASO - Armored Scrum Object`),
3. spaceless variants (`280Z-ZZAP` → `280zzzap`, `3wonders` → `3 Wonders`).

Artwork lands in `_Arcade/media/<game>.png` (+ `<game>-BG.png`), shows up as
the `_Arcade` row in `download_report.csv`, and honors the same options
(`--dry-run`, `--limit`, `force`, backgrounds, optimized thumbnails).

```ini
[arcade]
enabled=1               ; 0 = never scrape _Arcade
include_alternatives=0 ; 1 = also scrape _Arcade/_alternatives/*.mra
```

Select it explicitly with `--systems _Arcade`, or via `systems=_Arcade` in
`config.ini`.

## Notes

- A few arcade titles have no artwork on the CDN (laserdisc games like
  `Dragon's Lair`, multigame/test tapes, genuine CDN gaps such as
  `280Z-ZZAP`/`Datsun 280 Zzzap`): they are listed in `no_artwork.csv` like
  any other system.
- Consoles and computers with small libretro coverage (VIC-20, ZX81, obscure
  European systems...) will have variable hit rates: this is exactly what
  Console Mode's default scraper would get on the device.
- If you ever want to refresh the CDN listings: delete the `cache/` folder.
- Be kind to the CDN: don't raise `jobs` too much (16 by default is fine).
